# 2026-10-12

## 博客样式升级（参照 hexo-theme-fomalhaut）

**目标**：参照 https://github.com/fomalhaut1998/hexo-theme-fomalhaut（基于 Butterfly 二次开发的卡片式站点模板）优化个人博客样式。

**用户选定方向**：
- 主色保持天蓝 `#49B1F5`（不换 fomalhaut 的抹茶绿 `#39C5BB`）
- 特色效果只加：头像呼吸灯、顶部导航磨砂改版（雪花/涟漪未选）
- 改造方式：**纯 CSS 注入**，不动 themes/ 源码

**环境事实（重要）**：
- Butterfly 主题版本 `5.7.1.260810`，位于 `themes/butterfly`（git submodule）
- **Butterfly 5.7.1 未暴露 `--theme-color` 变量**，主题色是编译进 CSS 的；自定义样式里需自行定义 `--theme-color`
- 主题已定义 `--card-bg` / `--card-box-shadow` / `--card-hover-box-shadow` / `--font-color` / `--btn-hover-color` 等变量；`.card-widget` 继承 `.cardHover` mixin（用 `--card-bg` + `--card-box-shadow` + 8px 圆角）
- 导航结构很精简：`#nav > #blog-info(>a.nav-site-title>img.site-icon+span.site-name) + #menus(>#search-button? + .menus_items + #toggle-menu)`，**没有 `#nav-right`**
- 导航状态类：`#page-header.nav-fixed`、`.not-top-img`、`.fixed`、`.nav-visible`
- 页面容器 id：首页 `#recent-posts`、文章 `#post`、归档 `#archive`、其他页 `#page`
- 右下角：`#rightside > #rightside-config-hide(#darkmode,#hide-aside-btn) + #rightside-config-show(#rightside-config,#go-up)`
- 暗色模式：`html[data-theme="dark"]`

**改动文件**：
1. `source/css/custom.css` —— 完全重写（约 700 行），17 个分区：设计令牌 / 全局基础 / 背景层 / 顶部导航磨砂 / 首页头图 / 首页文章卡 / 侧边栏卡片 / 头像呼吸灯 / 分页按钮 / 按钮与标签 / 文章页 / 归档分类标签页 / 页脚 / 右下角按钮 / 移动端抽屉 / 暗色模式 / 响应式。
   - 卡片：`rgba(255,255,255,.78)` + `blur(12px) saturate(150%)` + 发丝描边 + 圆角 18–22px + hover 上浮
   - 导航：44/40px 胶囊 hover、下拉菜单圆角磨砂、滚动后近实底 + 发丝线
   - 头像呼吸灯：`@keyframes btf-avatar-glow`，跟随主色（`--ag-ring`/`--ag-halo`）
   - 分页：40px 圆角方块，hover/current 走主色
   - 标签：胶囊 `999px` + 主色淡底
2. `_config.butterfly.yml` —— `search.use: local_search`（修复「搜索图标未显示」；hexo-generator-search 已安装，生成 search.xml）

**构建验证**：`hexo clean && hexo generate` 通过，33 文件；`public/js/search/local-search.js` 已生成；`public/css/custom.css` 28KB 已链接。
