## 2026-11-13

**新增**

- 右下角接进 Live2D 看板娘，模型是 Cubism 官方 sample 里的 Hiyori。渲染用 pixi 6 加 pixi-live2d-display 0.4（cubism4 构建），引擎和模型都自托管，不走 CDN
- 贴图从 2048 降到 1024、量化到 256 色，模型 4.8MB 压到 1.2MB（PSNR 39.7dB）。页面上人物只有 300px 宽，2048 是浪费
- 首屏 load 之后 2.6 秒才拉模型。手机上一开始只给右下角一个小圆钮，点了才下载
- 对话走后端 `/api/chat` 转 `127.0.0.1:3002`，流式返回。人设是访客版，跟站内 skill 那份不是一回事
- 限流两层：nginx 每分钟 20 次；应用层每 IP 每分钟 4 条、每天 40 条，全站每天 800 条

**修复**

- 自建解析源被限流时，前端原来会静默切到匿名公共源，会员曲目在那边只剩 30 秒试听。现在 429 和 5xx 一律当作「暂时忙」，同源退避重试三次（0.8 / 1.6 / 3.2 秒），仍失败就保留现有列表，不再降级

## 2026-11-12

**修复**

- 积压的 5 个提交推不上去：服务器没有 GitHub 写权限，`git push` 报 `could not read Username`。改用仓库级 SSH 部署密钥（ed25519，只授权 `blog` 仓库写权限），远端从 HTTPS 切到 `git@github.com`，仓库内用 `core.sshCommand` 指定密钥，未改全局 `~/.ssh/config`，不影响原有的 `github_actions` 密钥
- 换凭证后首次推送成功（`dfd7304..ed59764`），GitHub Actions「Deploy to GitHub Pages」通过
- 图标全部空白：Font Awesome 走 `cdn.jsdelivr.net`，国内网络时常拉不到。改成自托管（`source/libs/fontawesome`，6.7.2，只留 woff2，共 388 KB），与之前 pjax 换本地是同一个理由
- 名片里 GitHub 图标看不见：SVG 蒙版用的是品牌深灰 `#24292e`，深色卡片上等于隐形。深色主题改用浅色，浅色主题仍保留品牌色
- 滚动条亮带：自定义的 8px 主题色滑块在深色底上过于扎眼，改为 6px、默认 16% 不透明度，只在悬停或拖动时提亮
- 点视口边缘会冒出一条贴边亮线：星尘涟漪的光核正好生在画布边界上，半个径向渐变被 canvas 直接裁掉，看起来像渲染故障。现在生成点从边缘内收 28px，并给粒子加了「距边界 26px 内渐隐」，任何绘制都不会被硬切
- 名片里 GitHub 和邮箱两个圆形按钮高度对不齐：一个用 SVG 蒙版、一个用字体字形，同一个 1em 盒子，字形的墨迹只有 0.75em 高（实测 20.5px 对 15.8px）。现在两个都走内联 SVG 蒙版，信封靠蒙版自身比例收到 0.94em，横长 1.18em

**功能**

- 音乐页加歌词字幕：一次只显示一句，居中，按 LRC 时间轴二分查找当前句。换句先淡出 210ms 再换字淡入；间隔不到 1.1 秒的直接换
- 前奏还没唱到第一句时，首句用淡色摆着当预告。否则前奏长的歌这块要空二十几秒，看着像没加载
- 纯音乐不做空态，显示「纯音乐」加作曲 / 编曲。安静歌单 20 首里 16 首没有歌词，这是常态
- 服务端单开一条 `type=lyric` 路由，缓存 24 小时、独立一份 Map。主缓存只有 64 条，一个 51 首的歌单光歌词就能把播放地址全挤掉
- 歌单接口原来不带 `songId`，前端取不到曲目 id 就发不出歌词请求。现在每条多一个 `songId`

**部署**

- 启用 HTTPS：Let's Encrypt 自 2026-01 起支持纯 IP 证书，为 `47.98.233.253` 签了一张，nginx 改为 80/443 双端口服务
- IP 证书只能走 `shortlived` 档，160 小时就到期，因此加了 systemd 定时器每天两次续期，续期后自动 reload nginx；`--dry-run` 演练通过
- 没有强制 HTTP 跳 HTTPS：证书寿命只有 6 天，续期一旦断链，强制跳转就让人连退回 HTTP 的机会都没有

**内容**

- 补齐上一批未提交的改动：新增《看板娘入住博客啦》与两张配图，五篇旧文改口吻重写
- 名片头像与导航栏图标统一换成新插画：直接用原图（792×783）不做二次裁切，图本身是圆形构图，四角白底正好被 `border-radius: 50%` 的圆形遮罩切掉；两处引用同一个 URL，浏览器只下载一次

## 2026-10-28

**修复**

- 文章页渲染为空、生成的文件是 0 字节。原因是 `hexo-util` 的 `Pattern` 未做首尾锚定，把 `source/css/_layout/*.styl` 误判成主题布局，覆盖了 `post.pug`。改为在 `scripts/fix-theme-views.js` 里生成前清理误注册的样式视图
- 导航栏左上角圆形头像被上下裁切。`#blog-info` 继承了 `.limit-one-line` 的 `overflow: hidden`，把 36px 头像连同描边一起切掉了
