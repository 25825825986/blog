## 2026-11-11

**新增**

- 侧边栏时间卡片：大号时钟、今日进度、问候语，附农历与节气（1900–2100 逐日回测）
- 左下角常驻音乐播放器：接自建解析服务，支持多歌单切换、播放进度记忆、封面旋转
- 开启 pjax：站内跳转从 36 个请求降到 4 个，传输从 527 KB 降到 10.8 KB

**修复**

- pjax 后首页副标题空白：脚本往已被替换的旧节点里打字，改为每次启动重取元素，并用代数作废旧异步链
- pjax 后笔尖光标失效：补 `pjax:complete` 监听
- pjax 库默认走公共 CDN，在服务器上不可达，改为本地加载

**内容**

- 新增《加个播放器，顺手砍掉 98% 加载》

## 2026-10-28

**修复**

- 文章页渲染为空、生成的文件是 0 字节。原因是 `hexo-util` 的 `Pattern` 未做首尾锚定，把 `source/css/_layout/*.styl` 误判成主题布局，覆盖了 `post.pug`。改为在 `scripts/fix-theme-views.js` 里生成前清理误注册的样式视图
- 导航栏左上角圆形头像被上下裁切。`#blog-info` 继承了 `.limit-one-line` 的 `overflow: hidden`，把 36px 头像连同描边一起切掉了
- 右下角悬浮按钮看不清。图标是纯白、底色又是 78% 半透明白，叠在白色卡片上几乎隐形

**优化**

- 悬浮按钮改为接近实白底 + 主色图标，补描边和阴影；容器 `opacity` 从 0.8 提到 1，暗色模式单独配色

**内容**

- 新增「博客搭建分享」分类
- 两篇占位文章替换为正式内容：《这个站，空了十个月》《这个站都改过什么》

## 2026-10-13

- 部署认证从 PAT 改为 Deploy Key，绕开 token 作用域问题
- 工作流在部署前增加 SSH 认证预检，配错时给出明确报错，而不是难懂的 git 403

## 2026-10-12

- 部署方式切换到 GitHub Pages，产物推到独立仓库

## 2026-03-11

- 接入 GitHub Actions 自动部署，推送到 `main` 即自动构建发布
- 修复部署后页面空白的问题

## 2025-05-18

- 更新 Butterfly 主题

## 2025-05-12

- 修复日夜模式切换时夜间流星特效残留——改为按 `data-theme` 判断，切回白天时清空画布
